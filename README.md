# THE CARD GAME 🃏

> *"Chi sta veramente giocando?"*

Un card game metanarrativo ispirato a Inscryption, dove le regole del gioco sono solo l'inizio della storia.

## 🎮 Gioca Ora

Apri semplicemente `index.html` nel tuo browser o visita il sito su GitHub Pages.

## 📖 Come Si Gioca

### Obiettivo
Riduci la salute dell'Entità a 0 prima che lei faccia lo stesso con te.

### Meccaniche Base

1. **Anime (🜏)**: La valuta del gioco. Ogni carta costa anime per essere giocata.
   - Inizi con 0 anime
   - Guadagni +1 anima all'inizio di ogni round
   - Puoi sacrificare le tue carte per ottenere 1 anima

2. **Carte**: Ogni carta ha:
   - **Costo**: Quante anime servono per giocarla
   - **Attacco (ATK)**: Danno che infligge
   - **Salute (HP)**: Quanto danno può subire
   - **Abilità**: Effetti speciali (alcune carte)

3. **Campo di Battaglia**:
   - Hai 4 slot dove giocare le carte
   - L'Entità ha anche lei 4 slot
   - Le carte si affrontano in posizioni corrispondenti

### Turni

**Il Tuo Turno:**
- Pesca una carta all'inizio del round
- Gioca carte dal tuo mano (trascina e rilascia)
- Puoi sacrificare carte per ottenere anime
- Premi "Termina Turno" quando hai finito

**Fase di Combattimento:**
- Le tue carte attaccano
- Se c'è una carta avversaria nella stessa posizione, si scontrano
- Se non c'è una carta avversaria, colpisci direttamente l'Entità

**Turno dell'Entità:**
- L'Entità gioca le sue carte
- Le sue carte attaccano
- Se colpiscono direttamente, perdi salute

### Carte Speciali

- **Ombra Errante** (0🜏): Economica ma debole, evasiva
- **Corvo Profetico** (1🜏): Ti fa pescare una carta extra
- **Cultista** (1🜏): Genera 1 anima a fine turno
- **Marionetta** (0🜏): Può essere sacrificata più volte
- **Anomalia** (1🜏): Abilità misteriose...
- **Araldo** (1🜏): Ti guarisce quando giocato

## 🌀 Elementi Metanarrativi

Questo non è un normale card game. Durante la partita noterai:

- **Messaggi Misteriosi**: L'Entità comunica con te
- **Glitch**: Il gioco si... distorce?
- **Eventi Meta**: Cose strane che rompono la quarta parete
- **Memorie Persistenti**: Il gioco ricorda...

*Più giochi, più scopri. O forse è il gioco che scopre te.*

## 🎯 Strategie

1. **Gestione delle Anime**: Non giocare tutte le carte subito. A volte sacrificare è meglio.
2. **Posizionamento**: Metti le carte più forti contro le minacce più grandi.
3. **Carte Economiche**: Le carte a 0 anime sono perfette per riempire gli slot vuoti.
4. **Timing**: Alcune abilità si attivano in momenti specifici.
